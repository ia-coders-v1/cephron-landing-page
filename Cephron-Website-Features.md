## Why a private cloud

Drafted from PDF claims; pending approval.

**Public-cloud bills that never stop**
Steady workloads on a public cloud mean paying every month for capacity your own servers could provide. Cephron turns hardware you own into a private cloud, without paying for a public cloud.

**Tools only experts can run**
Running virtual machines often means the command line and waiting on the one person who knows it. Cephron does every task, from first install to VM console, in a clean web interface, without the command line.

**VMs trapped on one platform**
Moving between platforms should not mean starting over. Cephron imports VMs from VMware, Hyper-V, VirtualBox, Proxmox and the cloud, and exports any VM's disk and settings, so your VMs are never locked in.

## Create a VM in minutes

A guided wizard takes you from nothing to a running server, with no guesswork.

**7-step creation wizard**
Name it, pick what it boots from, size it, add disks and networks, set up the login, review and go. Every step explains itself.

**Start from anything**
Launch from a ready template, a cloud image, an ISO installer, or a blank disk that boots from the network.

**Ready to log in on first boot**
Set the host name, user, password and SSH key up front. The VM configures itself the moment it starts.

**Windows 11 ready**
UEFI, Secure Boot and a virtual TPM are one click away, so modern Windows installs without workarounds.

**No surprises on size**
Cephron shows how much of your quota a new VM will use and stops you before you run out.

**Templates for repeat work**
Built-in templates for Ubuntu, Debian, Fedora and Windows Server, plus your own custom recipes.

## Run and control every VM

Everything you need to operate a VM is on one page.

**One-click power control**
Start, stop, pause and restart one VM or many at once. Force power off is there for a stuck machine.

**Console in your browser**
See and use the VM's screen straight from the browser. No plugins, no extra software. Send Ctrl+Alt+Del and go full screen.

**Live screen preview**
A small live picture of each VM's screen tells you at a glance whether it booted.

**Snapshots and instant undo**
Save a VM's state before a risky change. If something breaks, restore it in one click.

**Change hardware any time**
Add CPUs, memory, disks or network cards as your needs grow.

**Performance at a glance**
CPU, memory, disk and network graphs for every VM, plus its IP address and guest status.

## Share one host between many teams

Nodes split your hardware into private, guaranteed slices.

**Guaranteed resources**
Each node gets its own CPU cores, memory and disk. One team can never slow another down or use its space.

**Separate logins**
Every node has its own user. They see only their own VMs, disks and networks.

**Flexible CPU sharing**
Give a node dedicated cores for steady speed, or let VMs share cores (up to 8x) to fit more on the same hardware.

**Self-service for teams**
Node users create and manage their own VMs, disks, private networks and published ports, without waiting on IT.

**Always fits**
Cephron checks every new node against the host's free capacity before creating anything.

**Full visibility**
See each node's usage, VMs and sign-in history from one page.

## Built to stay up

Grow from one server to a cluster, and keep VMs running through failures and maintenance.

**Multi-server clusters**
Add servers with a simple join code. Cephron tells you when the cluster can survive a server failing.

**Maintenance without downtime**
Put a server into maintenance and its VMs move to other servers, live where possible. Update, restart, bring it back.

**Live migration**
Move a running VM to another server without switching it off.

**Replicated storage**
VM disks are stored in several copies across servers, so a failed disk or server does not lose data.

---

## Storage and networking made simple

Powerful infrastructure, presented in plain words.

**Thin disks**
Disks use real space only as data is written, so your storage goes further.

**Image library**
Upload images and ISOs, or import them from a link. Every VM gets its own copy, so originals stay clean.

**Clear storage view**
See total, used and free space, every disk in every server, and which VM uses which volume.

**Internet out of the box**
Every VM gets a working network by default, with no setup.

**VLANs and office networks**
Put VMs on your own network with their own addresses, and choose which teams may use each network.

**Private networks and published ports**
Let VMs talk only to each other, or open a single port so customers can reach a website or service.

---

## Move in from anywhere

Keep the VMs you already have.

**Import existing VMs**
Bring in VMs from VMware, Hyper-V, VirtualBox, Proxmox/KVM or a public cloud. OVA, qcow2, VMDK, VHD, VHDX, VDI and raw files are supported.

**Export any time**
Download a VM's disk and settings for backup or to move it elsewhere. Your VMs are never locked in.

## Know what is happening

Monitoring and troubleshooting are built in.

**Health dashboard**
One home page shows capacity, hardware, alerts and recent activity, with quick-fix buttons for common issues.

**Performance history**
CPU, memory and network graphs for the last hour, day, week or month.

**Hardware health**
Temperatures and memory errors for every server, so you catch problems early.

**Full audit trail**
Every action is recorded with who did it and when. Long jobs show their progress and result.

**Logs in one place**
Read live logs from every server and service without logging in to each machine.

**One-click support bundle**
Collect logs and settings into a single file to share with support.

---

## Secure by default

Safe settings come first.

**Protected sign-in**
New accounts must set their own password, and repeated wrong guesses lock the account.

**Isolated teams**
Each node is walled off from the others, with its own permissions and network rules.

**Security reminders**
Cephron warns you when risky options, such as remote shell access, are left on.

**Guided first setup**
A setup wizard checks the hardware, prepares storage and adds servers before you go live.
